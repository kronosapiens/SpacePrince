# Archive

Design history kept deliberately, outside the active reading path.
Nothing here is current guidance; the maintained references are in the parent `docs/` directories.

## v1

The earlier design pass, from before the chart-to-chart combat model.
It defined a run as a sequence of **postures** (Think / Wait / Fast, after Siddhartha), a central resource called **Permission** earned by aligning actions with the chart, a late **Fixed Stars** layer where distinctions collapse, and **houses as progression tracks** unlocked over a Prince's life.
It is kept because the current design still refers to that lineage: the postures' sensibility survives in choosing how to engage rather than out-scaling, and the contract data model was the first statement of the onchain ambition.

- [CONTRACTS.md](v1/CONTRACTS.md): the v1 onchain data model for charts and synastry.
