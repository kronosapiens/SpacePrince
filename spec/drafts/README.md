# Working drafts

Drafts are proposals for discussion, separate from the current [encounter references](../mechanics/HOUSES.md#reading-the-encounter-references) and other design guidance.
Review completion describes work performed, not user acceptance or readiness for implementation.
Consult an active draft when continuing that task; consult an archive when investigating its history.

## Active work

- [Narrative encounter working guide](narrative-encounters/STYLE_GUIDE.md) — the single working document for the writing method, participation directions, useful examples, and review findings; revise in place and remove when the method is incorporated into the existing references.

## After review

With user approval, put accepted design conclusions into the relevant existing reference and accepted content into its maintained content source.
Retire the active draft when it no longer serves the work; retain a dated archive only when its history remains useful.
Source evidence needed by citations stays in [research](../research/README.md).
